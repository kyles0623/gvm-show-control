# Code of conduct

Be kind and assume good faith. This project is used by people running real shows, often under time pressure:
help them the way you'd want to be helped five minutes before curtain.

- Be respectful; no harassment, insults or personal attacks.
- Stay on topic; keep feedback about the work, not the person.
- Don't post other people's private information.

Maintainers may edit, hide or remove comments and issues that break these rules, and block people who keep
breaking them. To report a problem with someone's behavior, contact the maintainer through their GitHub profile.
